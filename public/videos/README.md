# Folder Video (Videos)

Simpan semua file video website Anda di dalam folder ini:
- Format rekomendasi: `.mp4`, `.webm`.
- Contoh: `showcase.mp4`, `background-video.mp4`, dll.

### Cara Memanggil Video di Next.js:
```tsx
<video
  src="/videos/showcase.mp4"
  autoPlay
  loop
  muted
  playsInline
  className="w-full h-full object-cover"
/>
```
